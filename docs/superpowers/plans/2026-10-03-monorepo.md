# Monorepo Morgen: implementatieplan

> **Voor agents:** VERPLICHTE SUB-SKILL: gebruik superpowers:subagent-driven-development (aanbevolen) of superpowers:executing-plans om dit plan taak voor taak uit te voeren. Stappen gebruiken checkboxes (`- [ ]`).

**Doel:** MorgenCompany.com (statisch) en MorgenAcademy.nl (React/Vite/Supabase) in één GitHub-repo (`morgenacademy/morgencompany.com`), met de volledige git-historie van allebei, terwijl de twee Netlify-projecten blijven bestaan.

**Architectuur:** De company-site verhuist naar `company/`, de academy-app naar `academy/`, specs en plannen naar een niet-publieke `docs/` in de root. Elk Netlify-project krijgt een eigen base directory (`company` resp. `academy`) en bouwt alleen als zijn eigen map verandert. Dat doet Netlify standaard: zonder eigen `ignore`-regel worden builds overgeslagen als er niets in de base directory veranderde. Bijvangst: de root van de repo wordt niet meer gepubliceerd, dus `CLAUDE.md`, specs, plannen en schrijfstijl staan niet meer publiek op morgencompany.com. De function-broncode wordt met `_redirects` afgeschermd.

**Tech stack:** git (`git mv` en `merge --allow-unrelated-histories`), Netlify (twee projecten), Node 20, `node --test` (company), vitest + Vite + puppeteer (academy), bash + curl (smoke-test).

**Spec:** geen apart spec-document. Besluit genomen in de Claude-sessie van 2026-10-03 (optie 2: monorepo met twee mappen en twee Netlify-projecten, géén samenvoegen tot één app). Achtergrond: memory `morgen-een-merk-architectuur`.

- [ ] **Stap 5: Smoke-test schrijven** in `scripts/smoke-live.sh`:

```bash
#!/usr/bin/env bash
# Rookproef op de live sites. Gebruik:
#   scripts/smoke-live.sh
#   COMPANY=https://deploy-preview-50--websitemorgencompany.netlify.app scripts/smoke-live.sh
set -u
COMPANY=${COMPANY:-https://morgencompany.com}
ACADEMY=${ACADEMY:-https://academy.morgencompany.com}
fail=0

status() { # verwacht url [methode]
  local got
  got=$(curl -s -o /dev/null -w '%{http_code}' -m 20 -X "${3:-GET}" "$2")
  if [ "$got" = "$1" ]; then echo "ok   $got $2"; else echo "FAIL $got (verwacht $1) $2"; fail=1; fi
}
contains() { # url tekst
  if curl -s -m 20 "$1" | grep -qF -- "$2"; then echo "ok   bevat '$2' $1"; else echo "FAIL mist '$2' $1"; fail=1; fi
}
header() { # url header-fragment
  if curl -sI -m 20 "$1" | grep -qiF -- "$2"; then echo "ok   header '$2' $1"; else echo "FAIL header '$2' ontbreekt $1"; fail=1; fi
}

echo "== company ($COMPANY)"
status 200 "$COMPANY/"
status 200 "$COMPANY/academy/"
status 200 "$COMPANY/projecten/"
status 200 "$COMPANY/blog/chat-zegt-het-toch/"
status 200 "$COMPANY/docs/academy-chat/chat.js"
status 405 "$COMPANY/api/chat"
header "$COMPANY/docs/academy-chat/chat.js" "max-age=2592000"
contains "$COMPANY/" "analytics.ahrefs.com"

echo "== niet publiek"
status 404 "$COMPANY/CLAUDE.md"
status 404 "$COMPANY/docs/superpowers/plans/2026-07-04-academy-ai-chat.md"
status 404 "$COMPANY/docs/schrijfstijl.md"
status 404 "$COMPANY/netlify/functions/chat.mjs"
status 404 "$COMPANY/package.json"

echo "== academy ($ACADEMY)"
status 200 "$ACADEMY/"
contains "$ACADEMY/" '<h1'
contains "$ACADEMY/login" 'id="root"'

echo "== domeinen"
status 301 "https://www.morgencompany.com/"
status 301 "https://www.morgenacademy.nl/"
contains "https://morgenacademy.nl/login" 'id="root"'
contains "https://morgenacademy.nl/portal/pharmapartners" 'id="root"'

exit $fail
```
